# Guía de Desarrollo - Casinelect\n\nBienvenido a la guía de desarrollo de Casinelect. Este documento contiene información para configurar tu entorno de desarrollo.\n\n## Configuración del Entorno\n\n### Requisitos Previos\n\n```bash\n- Node.js 18.x LTS\n- npm 9.x\n- PostgreSQL 13+\n- Redis 6+\n```\n\n### Instalación Inicial\n\n```bash\n# 1. Clonar repositorio\ngit clone https://github.com/josecasincubero/Casinelect.git\ncd Casinelect\n\n# 2. Instalar dependencias\nnpm install\n\n# 3. Configurar ambiente\ncp .env.example .env\n\n# 4. Iniciar desarrollo\nnpm run dev\n```\n\n## Estructura del Proyecto\n\n```\nCasinelect/\n├── frontend/          # Aplicación React/Next.js\n├── backend/           # API Express.js\n├── database/          # Esquemas y migraciones\n├── docker-compose.yml # Configuración Docker\n└── README.md          # Documentación principal\n```\n\n## Scripts Disponibles\n\n```bash\nnpm run dev              # Iniciar servidor de desarrollo\nnpm run build            # Build para producción\nnpm run test             # Ejecutar tests\nnpm run test:coverage    # Coverage de tests\nnpm run lint             # Verificar linting\nnpm run format           # Formatear código\n```\n\n## Contribuir\n\nVer [CONTRIBUTING.md](./CONTRIBUTING.md) para conocer el proceso de contribución.\n\n## Soporte\n\n¿Tienes problemas?
