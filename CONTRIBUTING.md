# Contribuyendo a Casinelect

¡Gracias por tu interés en contribuir! Este documento proporciona las directrices para hacer contribuciones.

## Código de conducta

Todos los contribuidores deben seguir nuestro código de conducta, que resume la esencia del respeto y la inclusión.

## Cómo reportar bugs

1. Antes de abrir un issue, verifica si el bug ya fue reportado
2. Si no existe, crea un nuevo issue con:
   - Título descriptivo
   - Descripción clara del problema
   - Pasos para reproducir
   - Comportamiento esperado vs. actual
   - Screenshots si aplica
   - Tu ambiente (OS, navegador, versión)

## Cómo sugerir features

1. Usa un título claro y descriptivo
2. Proporciona descripción detallada de la funcionalidad
3. Explica por qué esta feature sería útil
4. Lista ejemplos de cómo funcionaría

## Pull Requests

1. Fork el repositorio
2. Crea una rama (`git checkout -b feature/amazing-feature`)
3. Commit tus cambios (`git commit -m 'Add amazing feature'`)
4. Push a la rama (`git push origin feature/amazing-feature`)
5. Abre un Pull Request

### Estándares de código

- Usa ESLint y Prettier
- Escribe comentarios claros
- Incluye tests para nuevas funcionalidades
- Asegúrate que todos los tests pasen

### Convención de commits

```
feat: add new feature
fix: resolve bug
docs: update documentation
style: fix formatting
refactor: reorganize code
test: add tests
chore: maintenance tasks
```
