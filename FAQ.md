# Preguntas Frecuentes - Casinelect\n\n## Instalación\n\n### ¿Cómo instalo Casinelect?\n\n```bash\ngit clone https://github.com/josecasincubero/Casinelect.git\ncd Casinelect\nnpm install\nnpm run dev\n```\n\n### ¿Qué requisitos necesito?\n\n- Node.js 18+\n- npm 9+\n- PostgreSQL 13+\n- Redis 6+\n\n### ¿Puedo usar Docker?\n\nSí, usa `docker-compose up --build`\n\n## Uso\n\n### ¿Cómo creo una cuenta?\n\n1. Ve a https://casinelect.com\n2. Haz clic en \"Registrarse\"\n3. Completa el formulario\n4. Verifica tu email\n\n### ¿Cómo agrego productos?\n\nComo administrador:\n1. Accede al panel de admin\n2. Ve a \"Productos\"\n3. Haz clic en \"Nuevo Producto\"\n4. Completa los detalles\n5. Guarda\n\n### ¿Qué métodos de pago acepta?\n\n- Stripe\n- PayPal\n- MercadoPago\n- Transferencia bancaria\n\n## Problemas Comunes\n\n### Error: \"Port 3000 already in use\"\n\nCambia el puerto:\n```bash\nPORT=3001 npm run dev\n```\n\n### Error de conexión a base de datos\n\nVerifica:\n1. PostgreSQL está corriendo\n2. `DATABASE_URL` en `.env` es correcta\n3. Credenciales son válidas\n\n### ¿Por qué es lento?\n\n- Verifica conexión a internet\n- Limpia caché: `npm run clean`\n- Reinicia servidor de desarrollo\n\n## Funcionalidades\n\n### ¿Hay soporte 24/7?\n\nActualmente no, pero puedes abrir un Issue en GitHub para obtener ayuda.\n\n### ¿Puedo contribuir?\n\n¡Por supuesto! Lee [CONTRIBUTING.md](./CONTRIBUTING.md)\n\n### ¿Es código abierto?\n\nSí, bajo licencia MIT\n\n## Seguridad\n\n### ¿Es seguro hacer compras?\n\nSí, usamos SSL/TLS y tokens JWT para seguridad.\n\n### ¿Cómo reporto una vulnerabilidad?\n\nContacta a security@casinelect.com\n\n## Desarrollo\n\n### ¿Cómo ejecuto tests?\n\n```bash\nnpm run test\n```\n\n### ¿Cómo hago un build para producción?\n\n```bash\nnpm run build\nnpm run start\n```\n\n### ¿Cuál es el stack tecnológico?\n\nVer README.md sección Tech Stack\n\n## Soporte\n\n- **Documentación:** [README.md](./README.md)\n- **Issues:** [GitHub Issues](https://github.com/josecasincubero/Casinelect/issues)\n- **Email:** support@casinelect.com\n- **Discord:** [Comunidad](https://discord.gg/casinelect)\n
