# API Documentation - Casinelect\n\n## Base URL\n```\nhttps://api.casinelect.com/v1\n```\n\n## Autenticación\n\nTodos los endpoints requieren un token JWT en el header:\n\n```bash\nAuthorization: Bearer <your_jwt_token>\n```\n\n## Endpoints Principales\n\n### Productos\n\n#### GET /products\nObtiene lista de productos\n\n```bash\ncurl https://api.casinelect.com/v1/products\n```\n\n**Response:**\n```json\n{\n  \"products\": [\n    {\n      \"id\": \"prod_123\",\n      \"name\": \"Refrigerador\",\n      \"price\": 1299.99,\n      \"stock\": 50\n    }\n  ]\n}\n```\n\n#### GET /products/:id\nObtiene un producto específico\n\n#### POST /products\nCrea un nuevo producto (Admin)\n\n#### PUT /products/:id\nActualiza un producto (Admin)\n\n#### DELETE /products/:id\nElimina un producto (Admin)\n\n### Carrito\n\n#### GET /cart\nObtiene el carrito del usuario\n\n#### POST /cart/items\nAñade item al carrito\n\n```json\n{\n  \"productId\": \"prod_123\",\n  \"quantity\": 2\n}\n```\n\n#### PUT /cart/items/:itemId\nActualiza cantidad de item\n\n#### DELETE /cart/items/:itemId\nElimina item del carrito\n\n### Órdenes\n\n#### POST /orders\nCrea una nueva orden\n\n```json\n{\n  \"items\": [{\"productId\": \"prod_123\", \"quantity\": 1}],\n  \"shippingAddress\": {...}\n}\n```\n\n#### GET /orders/:id\nObtiene detalles de una orden\n\n#### GET /orders\nObtiene órdenes del usuario actual\n\n### Usuarios\n\n#### POST /auth/register\nRegistro de nuevo usuario\n\n```json\n{\n  \"email\": \"user@example.com\",\n  \"password\": \"secure_password\",\n  \"name\": \"John Doe\"\n}\n```\n\n#### POST /auth/login\nInicia sesión\n\n```json\n{\n  \"email\": \"user@example.com\",\n  \"password\": \"secure_password\"\n}\n```\n\n#### GET /auth/profile\nObtiene perfil del usuario actual\n\n#### PUT /auth/profile\nActualiza perfil del usuario\n\n## Códigos de Estado\n\n| Código | Descripción |\n|--------|-------------|\n| 200 | OK |\n| 201 | Created |\n| 400 | Bad Request |\n| 401 | Unauthorized |\n| 403 | Forbidden |\n| 404 | Not Found |\n| 500 | Internal Server Error |\n\n## Rate Limiting\n\n- 100 requests por minuto por IP\n- 1000 requests por hora por usuario autenticado\n\n## Webhooks\n\nConfigure webhooks en tu dashboard para recibir eventos en tiempo real:\n\n- `order.created`\n- `order.shipped`\n- `payment.completed`\n- `product.updated`\n\n## Ejemplos\n\n### JavaScript/TypeScript\n\n```typescript\nconst response = await fetch('https://api.casinelect.com/v1/products', {\n  headers: {\n    'Authorization': `Bearer ${token}`,\n    'Content-Type': 'application/json'\n  }\n});\n\nconst data = await response.json();\n```\n\n### cURL\n\n```bash\ncurl -H \"Authorization: Bearer your_token\" \\\n     https://api.casinelect.com/v1/products\n```\n\n## Soporte\n\nContacta a: api-support@casinelect.com\n
